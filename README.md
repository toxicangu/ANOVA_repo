# ANOVA_repo

Aplicación Streamlit para analizar los datos de `Datos_Complementarios_CLV.xlsx`.

Incluye ANOVA de un factor y ANOVA factorial para dos o tres factores, con interacciones, gráficas de interacción, heatmap de medias, diagnóstico de supuestos y comparaciones post hoc. Selecciona la hoja del socioformador en el menú lateral y ejecuta ambos tipos de ANOVA sobre cada base de datos requerida. La hoja `Historico_Ventas` se selecciona por defecto aunque su nombre tenga diferencias de acentuación; usa **Actualizar datos del Excel** para cargar los cambios más recientes del archivo.
